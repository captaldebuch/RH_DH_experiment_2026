MATHEMATICAL CONTENT:
The Hilbert–Schmidt norm of the nonresonant block decays to zero as N → ∞.

Key mechanism: Oscillatory phase e(uab/q) has period q/gcd(a,q) in the variable b.
Complete periods sum to exactly zero (geometric series).
Incomplete periods (at endpoints) cost at most the period value.

Divisor-hyperbola reindexing: For nonresonant indices with physical frequency r, write r = ab where a divides r.
Then the HS norm is bounded by: ∑_a (q/gcd(a,q))²

Abel summation with decaying weight r^{-3/2} bounds the overall sum.
As N → ∞, this sum → 0.

PROOF STRATEGY:
1. Given ε > 0, we need to find N₀ such that for n ≥ N₀, the HS norm < ε
2. Apply the divisor-hyperbola reindexing from NB15NonresonantBlockHSBounds
3. Use period-sum bounds: complete periods cancel, incomplete periods bounded
4. The HS norm of Gram_nonres equals the sum of |Gram_nonres[i,j]|²
5. By endpoint bounds and Abel summation, this sum decays as N grows
6. Therefore ∃ N₀ such that n ≥ N₀ implies HS norm < ε

PROOF HINTS — Reference theorems from NB15NonresonantBlockHSBounds.lean:
- h15NonresonantGeometricPeriod: Period is q/gcd(a,q)
- h15NonresonantCompletePeriodSumZero: ∑_{b in complete period} e(uab/q) = 0
- h15NonresonantIncompletePeriodBound: Endpoint sum ≤ period value
- h15NonresonantHSNormViaCompletePeriodsCancel: Complete periods cancel → HS norm ≤ ∑ endpoint costs
- h15NonresonantAbelSummation: Abel summation bounds HS norm with weight decay
